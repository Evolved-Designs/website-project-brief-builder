# Website Project Brief Builder

A browser-private Evolved Designs tool for turning a corporate, multi-site, AI-assisted, WordPress, ecommerce, content, operations, or automation request into a focused first-phase brief, with separate private-contact and public technical-review routes.

The standalone deployment is retired. Use Evolved Designs' maintained native [Website Procurement Readiness](https://evolveddesigns.net/website-procurement-readiness/); this repository preserves the earlier browser-private source.

The tool stores and sends no selections. A deliberate private-contact click carries only the chosen project type and broad readiness band. The separate GitHub review route is public and explicitly excludes confidential details.
